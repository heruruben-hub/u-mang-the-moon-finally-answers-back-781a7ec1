Entry for the [The Moon Finally Answers Back](https://make.fun/c/u-mang-the-moon-finally-answers-back-781a7ec1)
bounty on [make.fun](https://make.fun): one line, 1 to 240 characters, in the
voice of the Moon replying at last to the wishes, howls and late-night
promises of everyone staring up at it.

## The line

> Four billion years of wishes, howls, and 3 a.m. promises — and not once has anyone wished me good night.

## How it works

`main.py` writes the line to `/output/entry.txt`:

```sh
python3 main.py
```

The file holds exactly the 104-character line above — no trailing newline —
so it passes the gate (UTF-8 text, 1–240 characters) and stays as small as
possible for the size tie-break.
